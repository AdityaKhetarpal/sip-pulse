# SIP Pulse

**When the Nifty 50 falls, do Indian mutual fund inflows keep coming or dry up?**

A data project on AMFI's monthly mutual fund data from April 2019 to October 2026, set against the Nifty 50.

Work in progress. The question, hypotheses and test were fixed before any data was seen:
[design](input/ideas/sip-pulse-design.md) · [plan](input/ideas/sip-pulse-plan.md) · [change log](knowledge/_meta/log.md)

Data: [AMFI](https://www.amfiindia.com/research-information/amfi-monthly) (credited on every chart). Analysis for education, not investment advice.
